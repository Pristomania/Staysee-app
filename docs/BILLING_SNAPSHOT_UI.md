# StaySee AI — снимок тарифа и интерфейс, 20.11.2026

## Итог

Подготовлена096 и связка серверного снимка с PlanProvider, счётчиком, карточками тарифов и корректным отказом. **Ничего не выложено/не закоммичено, продажи выключены.** Код памяти, модели, ключи, другая рабочая копия не менялись. Живой provider callback/архивные RLS ещё не готовы.

- get_my_billing_snapshot без user_id аргумента использует auth.uid. Ровно собственные безопасные поля, без денег/платёжных ссылок/других людей. Время после блокировки usage. Проекция истёкшего тарифа на free/0trial не обновляет таблицу/счётчики.
- Новый контроллер проверяет схему/владельца/даты и использует монотонное время с консервативным серверным якорем. История серверных timestamps (с микросекундами) и монотонная опора не теряются при null/отзыве. Старый снимок не отменяет более новый free/отзыв.
- На expiry даже без сети функции закрываются, новые сообщения не начисляются. Купленные пакеты считаются отдельно и истекают по серверной временной опоре. Нулевой баланс не закрывает ещё оплаченные функции.
- Сон/ручной перевод часов, foreground/pageshow/focus/online требуют нового подтверждения. Запрос, пересёкший остановку monotonic/сдвиг wall-clock, не скрывает пробуждение. Wall-clock может только вызвать перепроверку, никогда — открыть/продлить доступ.
- Неудачная обычная сеть сохраняет известный снимок до deadline. Успешный null/неправильный ответ/смена пользователя не сохраняют старые права. Ожидание15сек, отмена, request generations, cleanup таймеров. Ни один render нового UID не использует старый тариф/счётчик.
- UI при неизвестном состоянии говорит «Проверяем тариф»/«Не удалось проверить тариф», не требует оплатить заново. Это учтено в кабинете/тарифах, диалоге, общих закрытых панелях/бейджах. Открытое предложение оплаты привязано к identity/tier/loaded и сбрасывается при изменении. Удаление памяти в закрытой панели не привязано к коммерческому loaded-флагу.
- Для previously-paid нет даты/обещания новых50 ни в счётчике, ни в карточке free. У purchased срока — строка «Оплачен до», а не «сообщения обновятся». Never-paid free и legacy manual сохраняют прежнюю совместимость.
- reserve096 добавляет только can_renew_messages к ответу095. Parser проверяет boolean; при false Edge даёт спокойный отказ без новой бесплатной/месячной квоты. UI не заменяет этот авторитетный отказ старой датой из замыкания отправки.
