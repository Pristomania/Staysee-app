# Robokassa documents implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Работа самостоятельно в текущей изолированной копии.

**Goal:** Добавить на существующий stayseeai.online согласованные документы приложения и прямые ссылки из регистрации, сохранив лист ожидания.

**Architecture:** Канонические тарифы серверного plans.ts читаются единым загрузчиком юридических Markdown; из развёрнутых документов строятся HTML, встроенные тексты и хеши. Публичные карточки показывают только free/basic и пакет; Premium в backend сохраняется.

**Tech Stack:** React, TypeScript, Vite, Node.js, генераторы Markdown/HTML, GitHub Actions, существующий nginx без изменения конфигурации.

**Spec:** docs/superpowers/specs/2026-11-28-robokassa-documents-design.md и уточнения Насти в чате.

## Global Constraints

- Сохранять главную для листа ожидания; не трогать его API/админку/базу/privacy.html.
- Не менять серверные планы, модели, память, миграции, секреты, DNS или nginx.
- Новые цены не придумывать; публичные тарифы free/basic, пакет из PACK.
- До выкладки показать юридические изменения «было → стало» и дождаться согласования; не отправлять письмо и не менять магазин.

## Review Focus

- Хеш регистрации соответствует развёрнутой оферте с тарифами, а не шаблонному маркеру.
- Изменение канонических тарифов обновляет и оферту, и карточки без второй таблицы чисел.
- Premium не становится доступным к покупке через новый публичный UI; старые права не удаляются.
- Внешние юридические ссылки не сбрасывают форму и флажки регистрации.
- При публикации только документов лист ожидания, кабинет и файлы данных побайтно сохранены; заявления о России не опережают фактический перенос.
