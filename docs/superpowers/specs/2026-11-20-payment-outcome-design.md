# StaySee AI: результат оплаты

Согласовано пользователем 20.11.2026 в чате.

После подтверждения оплаты **и фактической выдачи доступа** показать отдельный результат: «Тариф „Базовый/Премиум“ подключён», доступные сообщения/число бесед/функции, точная дата оплаченного срока и кнопка «Перейти к беседам». Для пакета — «Добавлено 100 сообщений», без обещания смены тарифа/срока. При оплате без выдачи прав — «Подключаем ваш тариф…», без предложения заплатить снова. Тестовый успех явно не выдаётся за настоящее подключение.

Подход: переиспользуемый компонент результата, в текущей тестовой панели подключается только тестовый вариант. Toast слишком легко пропустить, отдельный новый маршрут пока не нужен: карточка заменяет основное содержимое панели по подтверждённому результату. Боевой источник статуса/выдача прав ещё не реализованы, поэтому реальные варианты проверяются изолированно, не подключаются к фиктивному статусу и не включают продажи. Данные о сроке берутся из подтверждённого результата, не вычисляются от открытия страницы. Нереализованный ИИ-голос не обещать.

Кнопка ведёт в существующий список бесед (`main`), не создаёт новую и не тратит сообщение. Возврат/обновление не создаёт заказ или доступ. Просроченная/невалидная дата не должна давать ложное «подключён». Стиль существующей темы, адаптация 390px и клавиатура. Не менять модели/память, секреты, production или работу параллельного Claude.

Уточнение независимого review: для настоящего результата тарифа обязательны `paidUntil` и `verifiedAt` — срок и время **свежей серверной проверки текущих прав**, а не исторического callback. Оба — корректные календарные ISO timestamps с явным поясом, допустимы PostgreSQL доли до 6 знаков. Часы устройства не используются. Без свежего серверного подтверждения карточка не заявляет активный доступ. Будущий адаптер обязан проверить владельца/заказ/продукт и текущую выдачу; этот UI не декодирует непроверенный JSON или query.

Реальные платежи, новая выдача доступа и письма — вне этого небольшого интерфейсного этапа. Код оставляется в текущей изолированной ветке без commit/deploy, как ранее.
