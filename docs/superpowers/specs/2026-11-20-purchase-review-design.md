# Подтверждение условий перед тестовым заказом

Магазин ещё на проверке; пользователь выбрал Робочеки. Продолжаем локальный тестовый путь, не включаем реальные покупки/чеки и не меняем фискальную схему. Сначала человек выбирает продукт и видит условия, затем отдельным действием создаёт тестовый заказ, и только после этого может перейти в тестовую кассу. Отмена не вызывает API/не сохраняет попытку. Настоящие кнопки «Оплата скоро», gate и allowlist остаются прежними.

Подход: встроенная карточка проверки условий в существующем PaymentTestPanel, не модальное окно с отдельной ловушкой фокуса. Данные из PLANS/PACK, без дублирования цены/лимитов. Нет preview как источника прав/окончательной eligibility: реальные условия применения проверяет сервер, тест ничего не подключает. Premium: полная4900₽, новый30дневный срок после подтверждения, прежний включённый остаток не переносится, купленные сообщения остаются с прежним сроком. Месячная покупка завершает пробный остаток, будущие free50 после любой покупки не возвращаются. Пакет:100 за590₽,12месяцев, расход после включённого лимита, тариф/его срок/функции неизменны, первоначальный пробный остаток при первой докупке сохраняется. Разовая покупка — только тестируемый путь, не утверждать готовность автоподписки.

Карточка владеет только выводом и кнопками «Отмена»/«Создать тестовый заказ». Ticket review привязан к userId,api,storage,controller; смена любой привязки или phase делает его недействительным. Начать заказ можно только после нажатия подтверждения, повторный быстрый клик не создаёт второй благодаря существующей защите контроллера. Тестовая успешная карточка и повтор выбора продукта сохраняются. Не менять controller/grant/test/live protocol ради UI.

Перед подключением статуса к UI закрыть два отмеченных Minor101: нормализовать UUID, сделать согласованное микросекундное время для карточки currentGrant, не возвращать active+«период завершён». Только эти две локальные правки, с регрессиями, без изменения правил доступа.

Приёмка: чистые business-copy тесты и настоящий renderToStaticMarkup карточки (нет скрытого form/вызовов при render), RED→GREEN; регрессии UUID/microtime RED→GREEN. Настоящий локальный браузер без сетевых запросов: выбрать/отменить/подтвердить, повторная проверка после test_paid, быстрая двойная кнопка, смена пользователя, экран390px. Полные offline/SQL/types/build, одно свежее итоговое ревью. Реальная Робокасса/чеки/платежи/подписка отдельно не проверяются.
